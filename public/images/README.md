# セルフケア画像の入れ方

各エクササイズの画像は、このフォルダ内の **エクササイズごとのフォルダ** に置くだけで、
サイトに自動で表示されます（本文ファイルの編集は不要です）。

動画（YouTube）を入れたい場合は `docs/youtube-guide.md` を参照してください。
画像と動画は両方同時に設定できます。

## 基本の運用（3枚構成）

各フォルダに、次の **3枚** を置くのが基本です。
**ファイル名で役割が決まります。** 中身は写真だけでOKで、文字を入れる必要はありません
（ラベルや手順の文章はサイト側が表示します）。

| ファイル名 | ページでの表示 |
| --- | --- |
| `start.jpg` | ○ 開始姿勢（緑ラベル） |
| `end.jpg` | ○ 終了姿勢（緑ラベル） |
| `ng.jpg` | ✕ ダメな例（赤ラベル） |

- 並ぶ順番は **開始姿勢 → 終了姿勢 → ダメな例** で固定です（ファイル名の順ではありません）
- スマホでは縦に3枚、パソコンでは横に3枚並びます。タップで拡大できます
- 3枚そろっていなくても大丈夫です。ある分だけ表示されます

### 画像の下に一言を付けたいとき

ファイル名のうしろに `_` を付けて説明を書くと、画像の下に表示されます。

- `ng_肩がすくんでいる.jpg` → ✕ ダメな例／説明「肩がすくんでいる」
- `start_手のひらを壁につく.jpg` → ○ 開始姿勢／説明「手のひらを壁につく」

### ルール

1. **置く場所**: `public/images/<ファイル名と同じ名前>/` の中
2. **対応形式**: jpg / jpeg / png / webp / gif / avif
3. `start` / `end` / `ng` の代わりに `開始姿勢` / `終了姿勢` / `ダメな例` という
   日本語のファイル名でも同じように認識します

## 解説を焼き込んだ1枚もの画像を置く場合

`start` / `end` / `ng` 以外の名前（例: `01.png`）で置くと、役割ラベルなしで表示されます。
1枚だけ置いた場合は、トリミングされずに全幅で表示されます。
画像の作り方は `docs/one-sheet-image-guide.md` を参照してください。

この置き方も引き続き使えますが、**手順や注意点を画像に焼き込むと、
あとから文章を直したいときに画像を作り直す必要があります。**
3枚構成にして文章はファイル側で管理するほうが、修正がラクです
（`docs/how-to-edit.md`）。

## 補足

- 画像を差し替えるときは、同じファイル名で上書きするだけでOKです。
- 並び順を変えたいときは、ファイル名の先頭の数字を変えてください。
- 手順や注意点の文章を直したいときは `docs/how-to-edit.md` を参照してください。
