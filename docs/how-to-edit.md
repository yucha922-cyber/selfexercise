# セルフケアの内容を直すには

各エクササイズの「タイトル・目的・実施方法・注意点」は、
**1エクササイズ＝1ファイル** で管理しています。

```
src/data/selfcare/<フォルダ名>.md
```

例: 胸筋ストレッチ → `src/data/selfcare/kata-chest-stretch.md`

ファイル名がそのままページのURLになります
（`kata-chest-stretch.md` → `/selfcare/kata-chest-stretch/`）。
画像を入れるフォルダ名も同じです（`public/images/kata-chest-stretch/`）。

## 直し方（GitHubの画面だけで完結します）

1. GitHubで `src/data/selfcare/` を開き、直したいファイルをクリック
2. 右上の **鉛筆アイコン（Edit this file）** をクリック
3. 文章を直す
4. 下の **「Commit changes」** を押す

数分後に公開サイトへ反映されます。

## ファイルの中身

```markdown
---
title: 胸筋ストレッチ
order: 11
duration: 約3分
difficulty: 1
symptoms: katakori, nekoze
parts: kata
tags: ストレッチ, 胸, 巻き肩
popularity: 68
youtube:
---

## 目的
縮こまった胸の筋肉を伸ばして巻き肩をリセットします。

## 実施方法
- 壁の横に立ち、壁側の肘を肩の高さに上げます。
- そのまま体を壁と反対方向へゆっくりひねります。

## 注意点
- 肩に痛みが出る場合は肘の高さを下げてください。
```

### よく直すところ

| 直したいもの | 場所 | 書き方 |
| --- | --- | --- |
| ページのタイトル | `title:` | そのまま書き換える |
| 目的の文章 | `## 目的` の下 | そのまま書き換える |
| 手順を直す | `## 実施方法` の下 | その行を書き換える |
| **手順を増やす** | `## 実施方法` の下 | `- ` で始まる行を1行足す |
| **手順を減らす** | `## 実施方法` の下 | その行を丸ごと消す |
| 手順の順番を変える | `## 実施方法` の下 | 行を入れ替える（番号は自動で振り直されます） |
| 注意点を増やす／減らす | `## 注意点` の下 | 手順と同じ |
| 動画を入れる | `youtube:` | YouTubeのURLを貼る（`docs/youtube-guide.md`） |

手順の番号（①②③）は自動で付くので、**自分で番号を書く必要はありません**。
`- ` で始まる行を並べるだけです。

### 設定部分（上の `---` で囲まれたところ）

| 項目 | 意味 |
| --- | --- |
| `title` | ページのタイトル（必須） |
| `order` | 表示順。小さいほど先に出ます |
| `duration` | 所要時間の目安 |
| `difficulty` | 難易度（★の数・1〜5） |
| `symptoms` | 症状カテゴリ。カンマ区切り（`src/data/categories.ts` 参照） |
| `parts` | 部位カテゴリ。カンマ区切り |
| `tags` | 検索用のタグ。自由に書けます |
| `popularity` | 人気度（ランキングの初期値） |
| `youtube` | YouTubeのURL。空ならば動画なし |

## 新しいエクササイズを増やすとき

1. `src/data/selfcare/_template.md` の中身をコピー
2. 同じフォルダに `新しい名前.md` として貼り付け（名前は半角英数字とハイフン）
3. 中身を書き換える
4. `public/images/新しい名前/` フォルダを作って画像を置く

コードを触る必要はありません。ファイルを1つ置けばページが増えます。

## うまく表示されないとき

ファイルの書き方に問題があると、公開が止まってエラーが出ます。よくある原因は次の2つです。

- 1行目が `---` になっていない／設定の下の `---` を消してしまった
- `## 実施方法` の見出しを消してしまった、または名前を変えてしまった

見出しは `## 目的` `## 実施方法` `## 注意点` の3つです
（`## やり方` `## 手順` `## 注意事項` と書いても認識します）。
