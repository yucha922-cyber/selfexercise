# YouTube動画の入れ方

各エクササイズのページには、解説画像のほかに **YouTube動画を1本** 埋め込めます。
設定するのは、そのエクササイズの本文ファイル（`src/data/selfcare/<フォルダ名>.md`）の
**`youtube`** の1行だけです。

## 手順

1. 動画をYouTubeにアップロードします
   （院内向けなら公開設定を **「限定公開」** にすると、URLを知っている人だけが見られます。
   　「非公開」にすると埋め込んでも再生できないのでご注意ください）
2. YouTubeの「共有」ボタンを押してURLをコピーします
3. GitHubで `src/data/selfcare/<フォルダ名>.md` を開き、鉛筆アイコンで編集します
4. 先頭の設定にある `youtube:` のうしろにURLを貼り付けます
5. 「Commit changes」で保存します

```
youtube: https://youtu.be/dQw4w9WgXcQ
```

## 貼り付けられる形式

次のどれをそのまま貼ってもOKです。`?t=30` などの余分な文字が付いていても動きます。

| 形式 | 例 |
| --- | --- |
| 共有URL | `https://youtu.be/dQw4w9WgXcQ` |
| PCのアドレスバー | `https://www.youtube.com/watch?v=dQw4w9WgXcQ` |
| ショート動画 | `https://www.youtube.com/shorts/dQw4w9WgXcQ` |
| 動画IDのみ | `dQw4w9WgXcQ` |

`youtube:` のうしろを空のままにすると、動画は表示されません。

## スマホ用に縦動画を入れる

スマホで見たときだけ、別の動画（縦向きの動画）を再生できます。
使うのは **`youtube_mobile`** の1行です。

```
youtube: https://youtu.be/dQw4w9WgXcQ          ← パソコン用（横長）
youtube_mobile: https://youtu.be/AbCdEfGhIjK   ← スマホ用（縦長）
```

- **スマホなど画面の狭い端末**では `youtube_mobile` の動画が、縦長のプレーヤーで表示されます
- **パソコンやタブレット**では、これまでどおり `youtube` の動画が横長で表示されます
- `youtube_mobile` を空欄にすると、スマホでも `youtube` の動画が表示されます
  （これまでと同じ動作です。無理に両方そろえる必要はありません）
- 貼り付けられるURLの形式は `youtube` と同じです。YouTubeショートのURLもそのまま使えます

> 画面に表示されない側の動画は読み込まれないため、2本設定しても通信量は増えません。

## 表示される場所

エクササイズ詳細ページの **一番上（タイトル・所要時間のすぐ下、「目的」の前）** に、
横幅いっぱいのプレーヤーで表示されます。
スマホ用の縦動画を設定している場合、スマホでは縦長のプレーヤーになります。

画像と動画の両方を設定した場合は、**上に動画・下に「参考画像」** の順で両方表示されます。
どちらか一方だけでも問題ありません。

## 注意

- 1ページに設定できる動画は、パソコン用とスマホ用で1本ずつです
- 動画が「非公開」だと埋め込み再生できません。院内向けは「限定公開」を使ってください
- 動画を入れても、`## 実施方法` と `## 注意点` の文章は消さずに残してください
  （検索・読み上げ・動画が再生できない環境のために必要です）
